SARAWAK HERITAGE INVENTORY - HOME-SCREEN ICON (launcher)

Put these 8 files online once (free, GitHub Pages), then add that address to your phones' home screens.

1. PUT THE FILES ONLINE (about 5 minutes, once)
   a. Sign in or sign up at github.com.
   b. "+" (top right) > New repository. Name: heritage   Public. Create repository.
   c. "uploading an existing file" > drag in ALL files from this folder
      (index.html, manifest.webmanifest, the 4 icon-/apple- PNGs, favicon.ico, favicon-32.png) > Commit changes.
   d. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder / (root) > Save.
   e. After 1-2 minutes the address appears at the top of that page, e.g.
      https://YOUR-NAME.github.io/heritage/

2. iPHONE (Safari)
   Open the address above in Safari > Share button > Add to Home Screen > Add.

3. ANDROID (Chrome)
   Open the address above in Chrome > menu (three dots) > Add to Home screen (or Install app) > Install.

Notes
- The app opens full-screen inside the launcher, with your icon and a splash screen.
- Deploying new versions of the Apps Script needs NO change here (the address stays the same).
- If the app ever won't load inside the launcher, add ?direct to the launcher address
  (https://YOUR-NAME.github.io/heritage/?direct) - it then opens the app page directly.
- If you ever create a NEW deployment (new /exec address), edit the APP line in index.html.
